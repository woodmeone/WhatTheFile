# 文件格式识别工具

一个简单的桌面应用程序，能够识别被修改后缀或未知格式的文件的真实格式。

## 功能特点
- 支持拖放文件进行识别
- 显示文件格式的匹配度和可能的扩展名
- 简洁直观的用户界面
- 可打包为独立的exe文件运行

## 使用方法

### 运行源代码
1. 克隆或下载本项目到本地
2. 安装依赖：
   ```
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```
   python main.py
   ```

### 打包为exe文件
1. 确保已安装pyinstaller：
   ```
   pip install -r requirements.txt
   ```
2. 执行打包命令：
   ```
   pyinstaller --onefile --windowed --icon=app_icon.ico main.py
   ```
3. 打包完成后，可在dist文件夹中找到生成的exe文件

## 工作原理
程序通过读取文件的前几个字节（文件头），与已知的文件格式签名数据库进行比对，从而识别文件的真实格式。

## 注意事项
- 对于某些特殊或罕见的文件格式，可能无法准确识别
- 加密或损坏的文件可能无法正确识别
- 打包时如果需要自定义图标，请将图标文件命名为app_icon.ico并放在项目根目录
